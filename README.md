## Cara menggunakan

Buka HTML di subfolder proyek. Jika proyek memerlukan server lokal, jalankan `python3 -m http.server 8000` dari folder proyek, lalu buka `http://localhost:8000`. Repo gabungan ini public sesuai pilihan pemilik.
